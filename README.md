# adimaginem
A computational ontology of Thomistic philosophy and psychology, designed for simulation.

The computational core will be written in Rust, with Python as its outer binding and possible orchestration layer. Every project-owned runtime or compile-time parameter is defined in [SNT3/DIPL](https://github.com/scinumtools/snt3) under [`dip/`](dip/). Other serialization formats are reserved for conventions or dependencies that require them.

See the [documentation](docs/index.md) for the source guide, scholarly method, architecture, and dependencies.
